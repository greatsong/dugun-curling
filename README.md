1. 태블릿을 **가로로** 들고 **[VPyLab에서 게임 열기](https://vpylab.vercel.app/sandbox?repo=greatsong/dugun-curling&autorun=1)**를 누르세요.
2. 3D 화면 오른쪽 위의 **[전체 화면]**을 눌러 실행 화면만 크게 보세요. 작은 화면에서는 손을 똑같이 움직여도 스톤이 더 세게 나가요.
3. **던지기**: 스톤을 손가락으로 누른 채 과녁 쪽으로 쓱 미는 도중에 손가락을 떼세요. 손가락을 멈췄다가 떼면 스톤이 나가지 않아요.
4. **비질**: 스톤이 움직이는 동안 손가락을 좌우로 빠르게 움직여 스톤 바로 앞을 문지르세요.
5. **단추와 메뉴**: [새 경기]와 [선수 시점으로 보기]는 손가락으로 누르면 돼요. [팀마다 스톤 4개]를 누르면 스톤 수를 고르는 목록이 열려요.
- 화면은 한 손가락으로만 만지세요. 던지는 도중에 다른 손가락이 닿았다 떨어지면 그 순간 스톤이 놓일 수 있어요.
- 아이패드에서는 화면을 한 번 만지면 그때부터 소리가 나요.

## 놀이 방법
1. **던지기**: 빨간 '손 떼는 선' 위의 스톤을 마우스(태블릿에서는 손가락)로 누른 채 과녁 쪽으로 끌다가 놓으세요. 스톤을 놓으면 그 순간 마우스가 움직이던 빠르기와 방향 그대로 출발해요. 각 팀의 첫 스톤 위에는 짧은 안내가 떠요. 스톤을 끄는 동안 주황색 화살표와 숫자가 지금 놓으면 어떤 속도로 출발할지 보여 줘요.
   - 손을 멈춘 채 놓으면 스톤이 나가지 않아요. 움직이면서 놓아야 해요.
   - 과녁을 향해 던지려면 옆에서 볼 때는 오른쪽으로, 선수 시점에서는 위쪽으로 끌어요.
2. **비질**: 스톤이 움직이는 동안 마우스(태블릿에서는 손가락)를 좌우로 빠르게 움직여 스톤 바로 앞의 얼음을 문지르세요. 문지르는 동안에만 빗자루가 나타나고 '비질 중!'이 떠요. 닦인 자국은 얼음에 남아요. 문지르기를 멈추면 얼음은 원래 상태로 돌아가요. Space 키를 누르고 있어도 비질이 돼요. 이 키를 쓰려면 먼저 3D 화면을 한 번 누르세요.
3. **차례와 점수**: 빨강 팀과 노랑 팀이 스톤을 한 개씩 번갈아 던져요. 오른쪽 위 메뉴(팀마다 스톤 ○개)에서 한 팀이 던질 스톤 수(1~8개, 처음엔 4개)를 고르고 [새 경기]를 누르세요. 모두 던지고 스톤이 멈추면 점수가 나와요.
4. **시점**: [선수 시점으로 보기]를 누르면 스톤 뒤에서 과녁을 바라보는 화면으로 바뀌어요. 화면은 움직이는 스톤을 따라가요. 스톤이 멈출 때쯤에는 시점이 과녁 위로 올라가 스톤들이 잘 보여요. [옆에서 보기]를 누르면 기본 실습처럼 스톤이 옆에서 보여요.

## 경기 규칙(실제 컬링 규칙을 간추린 것)
- 스톤이 **옆벽**에 닿거나 **뒷선**을 완전히 넘어가면 빠져요.
- 스톤이 주황색 **'넘어야 하는 선'**을 넘지 못하고 멈추면 빠져요.
- **점수**: 과녁(파란 원)에 닿은 스톤만 세요. 과녁 한가운데에 가장 가까운 스톤이 어느 팀 것인지 보세요. 그 팀만 점수를 얻어요. 상대 팀 스톤 중 한가운데에 가장 가까운 것과 비교해, 그보다 한가운데에 더 가까운 자기 팀 스톤을 하나당 1점으로 세요. 경기가 끝나면 점수에 포함된 스톤 위에 '1점'이 떠요.
- 과녁 한가운데까지 21.5 m예요. 얼음에서 비질 없이 스톤을 한가운데에 멈추게 하려면 약 6.6 m/s로 놓아야 해요.

## 코드에서 볼 곳
`main.py`의 '2. 법칙'만 읽어도 돼요.

```python
def 한_걸음(속도, 위치, 줄어드는_빠르기):
    빠르기 = mag(속도) - 줄어드는_빠르기 * 시간간격   # 방해가 있는 만큼만 빠르기가 줄어들어요
    if 빠르기 < 0:
        빠르기 = 0                                   # 방해는 멈추게 할 뿐, 뒤로 밀지는 않아요
    속도 = 빠르기 * hat(속도)                       # 방향은 그대로 두고 빠르기만 바꿔요
    위치 = 위치 + 속도 * 시간간격                    # 지금 속도로 한 걸음만큼 가요
```

- 기본 실습의 `한_걸음`과 무엇이 같고 무엇이 다른가요? (힌트: 응용판의 `속도`는 빠르기와 방향을 함께 담은 화살표예요. `mag(속도)`는 빠르기, `hat(속도)`는 방향이에요.)
- 손을 떠난 스톤을 앞으로 미는 코드가 있나요? 그런데도 스톤은 왜 계속 가나요?
- 비질은 무엇을 바꾸나요? 반복문에서 `방해 = 비질한_빠르기 if ... else 줄어드는_빠르기`를 찾아보세요. 방향은 바꾸지 않고 줄어드는 빠르기만 바꿔요.
- `부딪히기`: 무게가 같은 두 스톤이 부딪히면 맞닿은 방향의 속도를 서로 주고받아요. 정면으로 맞히면 던진 스톤은 그 자리에 멈추고, 맞은 스톤은 던진 스톤이 움직이던 빠르기로 나가요.
- `점수_계산`: 위의 점수 규칙을 그대로 코드로 쓴 함수예요.
- 스톤이 멈출 때마다 아래쪽 '콘솔 출력'에 `놓은 빠르기`, `미끄러진 거리`, `비질한 시간`이 한 줄에 기록돼요. 비질하지 않았을 때의 기록을 골라 미끄러진 거리가 빠르기² ÷ 2와 같은지 계산해 보세요. 얼음에서는 빠르기가 1초에 1 m/s씩 줄어들어요.

# 교사용 안내

## 실습의 뜻
- 법칙은 기본 실습과 같습니다. 응용판에서는 속도를 벡터로 나타냅니다. 걸음마다 **빠르기만** `줄어드는_빠르기 × 시간간격`만큼 줄이며, 빠르기가 0보다 작아지면 0으로 맞춥니다. 방향은 그대로입니다. 계산 순서도 시리즈 공통 규칙을 따릅니다. 빠르기를 먼저 계산한 뒤 위치를 계산합니다.
- 손을 놓은 뒤에는 스톤을 미는 코드가 없습니다. 스톤이 손을 떠나는 순간의 속도를 그대로 유지하려는 성질이 관성입니다. 비질은 '방해'만 줄입니다. 학생이 비질을 "밀어 주는 것"으로 오해하면 반복문의 `방해 = ...` 한 줄을 학생과 함께 살펴봅니다.
- 질량과 F = ma는 2편에서 다룹니다. 이번 실습에서는 충돌할 때 "무게가 같으면 맞닿은 방향의 속도를 주고받는다"는 결과만 적용합니다.

## 숫자 확인(검산)
- `python3 test_score.py`를 실행하면 점수 규칙 8가지와 법칙을 확인합니다. 4 m/s, 얼음(1) → 7.9967 m(참값 8 m보다 출발 빠르기 × 시간간격 ÷ 2 ≈ 3 mm 짧음), 6.6 m/s → 21.774 m, 비질만 계속(0.5) → 16 m.
- 얼음에서 비질 없이 스톤이 과녁에 남으려면 약 6.2~6.9 m/s로 던져야 합니다. '넘어야 하는 선'(15.1 m)을 넘으려면 약 5.5 m/s 이상으로 던져야 합니다. 비질을 끝까지 하면 약 4.4 m/s로도 과녁 앞쪽에 닿습니다.
- VPyLab에서 마우스 끌기 동작을 재현해 시험했습니다. 결과는 3.91 m/s → 7.64 m, 6.71 m/s → 22.51 m(둘 다 v²/2와 일치), 5.95 m/s에 비질 1.2초 → 21.19 m(비질 없이 17.7 m)입니다.

## 만든 방식에 대한 메모
- **던지기 빠르기**: 스톤을 잡고 있는 동안 화면에서 마우스의 위치와 그때의 시각을 기록합니다. 스톤을 놓기 직전 0.1초 동안의 이동량을 시간으로 나눈 값을 씁니다. 화면 높이를 1로 보고 잰 빠르기에 `손_배율`(기본 3)을 곱합니다. 화면의 오른쪽·위쪽 방향은 얼음 위에서 그에 해당하는 방향으로 바꿉니다. 얼음 위 거리로 재면 선수 시점에서 먼 곳일수록 같은 손놀림으로도 이동 거리가 몇 배로 커집니다. 그래서 화면을 기준으로 쟀습니다. 9 m/s를 넘으면 9 m/s로 줄입니다.
- **비질 알아보기**: 화면에서 스톤을 기준으로 최근 0.3초 동안 마우스(손가락)가 오간 길이를 잽니다. 이렇게 잰 길이에서 처음 위치와 마지막 위치 사이의 거리를 뺍니다. 던질 때처럼 화면 높이를 1로 보고 잽니다. 이렇게 구한 값이 0.12를 넘고 마우스가 화면에서 스톤 앞 1 m 지점을 기준으로 0.22 안에 있으면 비질로 봅니다. 화면을 기준으로 판단하므로 옆에서 볼 때도 선수 시점에서 볼 때도 손을 똑같이 움직이면 비질 판정이 같습니다. 비질은 가장 앞에서 움직이는 스톤 하나에만 적용됩니다.
- Space 키 입력은 3D 화면에 포커스가 있을 때만 인식됩니다. 버튼을 누른 직후에 Space 키를 누르면 그 버튼이 다시 눌릴 수 있습니다. 학생에게 먼저 3D 화면을 한 번 누르도록 안내합니다.
- 스톤이 잘 보이도록 반지름을 0.4 m로 그렸습니다(실제 반지름은 약 0.145 m). 과녁까지의 거리(21.5 m)는 기본 실습과 같고 실제 경기장에서의 거리와는 다릅니다. 회전(컬)과 스톤끼리의 마찰은 넣지 않았습니다.
- '넘어야 하는 선' 규칙은 실제 컬링의 호그 라인 규칙을 간추린 것입니다. 실제 경기에서는 다른 스톤을 맞히면 선을 넘지 못해도 던진 스톤이 남습니다. 이 실습에서는 던진 스톤이 선을 넘지 못하면 항상 빠집니다. 두 팀에서 각각 과녁 한가운데에 가장 가까운 스톤을 골랐을 때, 두 스톤이 한가운데에서 같은 거리에 있으면 0점입니다. 한 경기는 한 엔드입니다.
- 화면을 그리는 횟수(1초에 60번)에 맞춰 계산합니다. 느린 컴퓨터에서는 스톤이 천천히 움직이지만 멈출 때까지 이동하는 거리는 같습니다.
- 마우스로 화면이 돌거나 확대되지 않게 막아 두었습니다(`scene.userspin` 등). 화면을 두 번 누르면 VPyLab의 '화면에 맞추기'가 실행될 수 있습니다. 다음 스톤을 놓을 때 시점이 다시 맞춰집니다.
- **태블릿(터치)**: VPyLab은 손가락 터치를 포인터 이벤트로 받아 마우스 입력과 같은 방식으로 파이썬에 전달합니다. 손가락으로도 스톤을 쉽게 잡도록 누를 수 있는 범위를 스톤 둘레 1.8 m 안으로 정했습니다. 손가락은 화면에 닿아야 위치를 알 수 있으므로(마우스는 누르기 전에도 위치를 알 수 있습니다) 처음 누른 곳부터 손가락의 빠르기를 잽니다. 손가락이 하늘이나 3D 화면 바깥을 가리켜도 위치를 알 수 있도록 경기장 뒤에 보이지 않는 큰 벽을 세웠습니다. 팀마다 쓸 스톤 수를 손가락으로 쉽게 고를 수 있도록 슬라이더 대신 메뉴를 썼습니다.
- 크롬에서 터치 포인터 이벤트를 흉내 내 조작을 시험했습니다(1180×750 화면에서 던지기 6.3 m/s → 20.1 m, 문질러 비질하기, 단추·메뉴). 실제 아이패드·안드로이드 태블릿에서는 아직 시험하지 않았습니다.
